Gagnez une épée des Artisans d'Azure

Une lame de mousse montée à la main, tirée au sort le dimanche du festival parmi ceux qui ont amené quelqu'un à la cour.

Comment participer
  1. 1Invitez une personne à se créer un compte pour le Festival Médiéval.
  2. 2Votre code de parrain vous attend dans votre espace membre. Donnez-le à votre invité au moment où il ouvre son compte. Votre code de parrainage HRV4TN
  3. 3Si votre compte existe déjà et que quelqu'un vous a amené ici, inscrivez son nom dans la section « Qui est mon parrain » de votre espace.

Chaque personne que vous amenez ajoute votre nom une fois de plus dans le chapeau.
